## 實作選擇

- 日誌先記 `checkpoint_prepared`，再建 ref、完成遠端備份、記 `checkpoint`，讓接回知道原快照 commit。I/O 經 WorkspaceOps 注入，replay 保持純函式。
- 舊委任書缺 checkpoint 時採相容路徑，不增加原核准以外的遠端操作。
- 秘密檔名檢查採不分大小寫並檢查每個路徑段；本地模式依規格保留完整快照。這不是內容掃描。
- 回復點被移動或刪除不可藉一般 overrides 忽略；rollback 不用覆寫操作。
- 已準備但因遠端失敗而停住的 run 也允許 rollback，前提是本地 ref 與準備事件吻合。
- 來源 HEAD 與委任書基準不符時暫停，避免備份與核准內容對不上。
- 備份依本次 worker 的路徑限制放在 `docs/ai-cli_kernel/checkpoint-before.log`，檔案受既有 ignore 規則排除，不進入交付差異。
